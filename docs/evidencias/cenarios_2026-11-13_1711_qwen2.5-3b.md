```java
interface Observador {
    void atualizar(double temperatura);
}

interface Sujeito {
    void anexar(Observador o);
    void desanexar(Observador o);
    void notificar();
}

class EstacaoMeteorologica implements Sujeito {
    private final List<Observador> observadores = new ArrayList<>();
    private double temperatura;

    public void anexar(Observador o) {
        observadores.add(o);
    }

    public void desanexar(Observador o) {
        observadores.remove(o);
    }

    public void notificar() {
        for (Observador o : observadores) {
            o.atualizar(temperatura);
        }
    }

    public void setTemperatura(double t) {
        this.temperatura = t;
        notificar();
    }
}

class DigitalRelogio implements Observador {
    public void atualizar(double t) {
        System.out.println("Agora: " + t + " °C");
    }
}

public class Main {
    public static void main(String[] args) {
        Sujeito estacao = new EstacaoMeteorologica();
        Observador digitalRelogio = new DigitalRelogio();
        estacao.anexar(digitalRelogio);

        estacao.setTemperatura(25.5);
    }
}
```

**Explicação:**
- **Sujeito (EstacaoMeteorologica):** É a classe que mantém o estado de interesse (temperatura) e notifica os observadores quando esse estado muda. Ele implementa métodos para anexar e desanexar observadores, bem como um método para notificar todos os observadores.
- **Observer (DigitalRelogio):** Implementa a interface Observador e define o método atualizar para atualizar a representação visual da temperatura.
- **ConcreteSubject (EstacaoMeteorologica):** Armazena o estado de interesse (temperatura) e notifica os observadores quando esse estado muda, fazendo uso do método notificar.
- **ConcreteObserver (DigitalRelogio):** Mantém uma referência para o ConcreteSubject e implementa o método atualizar para atualizar a representação visual da temperatura.

**Como funciona:**
- Quando a temperatura muda, o ConcreteSubject (EstacaoMeteorologica) notifica todos os observadores (DigitalRelogio) associados, que atualizam sua representação visual.
- O uso incorreto poderia ser omitir o método notificar() em ConcreteSubject, o que resultaria em observadores que não seriam atualizados quando a temperatura muda.
