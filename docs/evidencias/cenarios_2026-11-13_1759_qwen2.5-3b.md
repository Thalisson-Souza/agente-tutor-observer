```java
interface Observador {
    void atualizar(String mensagem);
}

interface Sujeito {
    void anexar(Observador o);
    void desanexar(Observador o);
    void notificar();
}

class CanaisDeNoticias implements Sujeito {
    private final List<Observador> observadores = new ArrayList<>();
    private String mensagem;

    public void anexar(Observador o) {
        observadores.add(o);
    }

    public void desanexar(Observador o) {
        observadores.remove(o);
    }

    public void notificar() {
        for (Observador o : observadores) {
            o.atualizar(mensagem);
        }
    }

    public void setMensagem(String m) {
        this.mensagem = m;
        notificar();
    }
}

class Noticia implements Observador {
    public void atualizar(String mensagem) {
        System.out.println("Notícia: " + mensagem);
    }
}

public class Main {
    public static void main(String[] args) {
        CanaisDeNoticias canais = new CanaisDeNoticias();
        Noticia noticia1 = new Noticia();
        Noticia noticia2 = new Noticia();

        canais.anexar(noticia1);
        canais.anexar(noticia2);

        canais.setMensagem("Boa notícia! O Brasil venceu a Copa do Mundo!");
    }
}
```

O `Noticia` implementa a `Observador` interface e possui o método `atualizar` que é chamado quando um observador é notificado. Neste exemplo, a mensagem é impressa na tela.

Esta é uma implementação simples do padrão Observer. O `CanaisDeNoticias` é o `Subject` que mantém uma lista de `ConcreteObserver` (Noticia) e notifica todos quando há uma mudança de estado. O `Noticia` é um `ConcreteObserver` que implementa a `Observador` interface e atualiza quando notificado.
