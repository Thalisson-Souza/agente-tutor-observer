## D7

**Pergunta anterior do tutor (contexto fixo):** Quer saber mais sobre os participantes?

**Pergunta:** Dê um exemplo em Java do Observer.

```java
interface Observador {
    void atualizar(String mensagem);
}

interface Sujeito {
    void anexar(Observador o);
    void desanexar(Observador o);
    void notificar();
}

class Notificador implements Sujeito { // ConcreteSubject
    private final List<Observador> observadores = new ArrayList<>();
    private String mensagem = "Sem notificações";

    public void anexar(Observador o) { observadores.add(o); }
    public void desanexar(Observador o) { observadores.remove(o); }
    public void notificar() {
        for (Observador o : List.copyOf(observadores)) o.atualizar(mensagem);
    }
    public void setMensagem(String m) { this.mensagem = m; notificar(); }
}

class EmailNotificador implements Observador { // ConcreteObserver
    public void atualizar(String m) {
        System.out.println("Email enviado: " + m);
    }
}

class SMSNotificador implements Observador { // ConcreteObserver
    public void atualizar(String m) {
        System.out.println("SMS enviado: " + m);
    }
}
```

### Explicação

1. **Subject (Notificador)**: Esta classe implementa a interface `Sujeito` e mantém uma lista de observadores. Ela fornece métodos para anexar e desanexar observadores, bem como para notificar todos os observadores quando a mensagem muda.

2. **ConcreteSubject (Notificador)**: Esta classe é uma implementação concreta do `Subject`. Ela mantém o estado da mensagem e notifica todos os observadores quando esse estado muda.

3. **Observer (EmailNotificador e SMSNotificador)**: Estas classes implementam a interface `Observador` e definem a operação `atualizar`. Quando notificados, elas realizam a ação correspondente (enviar um email ou um SMS).

4. **ConcreteObserver (EmailNotificador e SMSNotificador)**: Estas classes são observadores concretos que mantêm uma referência ao `Notificador` e implementam a operação `atualizar` para enviar notificações via email ou SMS.
