```java
interface Observador {
    void atualizar(int novoValor);
}

interface Sujeito {
    void anexar(Observador o);
    void desanexar(Observador o);
    void notificar();
}

class Notificador implements Sujeito { // ConcreteSubject
    private final List<Observador> observadores = new ArrayList<>();
    private int valor;

    public void anexar(Observador o) { observadores.add(o); }
    public void desanexar(Observador o) { observadores.remove(o); }
    public void notificar() {
        for (Observador o : List.copyOf(observadores)) o.atualizar(valor);
    }
    public void setValue(int novoValor) { this.valor = novoValor; notificar(); }
}

class Monitor implements Observador { // ConcreteObserver
    public void atualizar(int novoValor) {
        System.out.println("Novo valor: " + novoValor);
    }
}
```

### Explicação

1. **Subject (Notificador)**: Esta é a classe que mantém uma lista de observadores e notifica-os quando o valor muda. A interface `Sujeito` define os métodos `anexar`, `desanexar` e `notificar`. A classe `Notificador` implementa `Sujeito` e armazena uma lista de observadores, notificando-os sempre que o valor é alterado.

2. **ConcreteSubject (Notificador)**: A classe `Notificador` é um sujeito concreto que mantém um valor e notifica todos os observadores quando esse valor muda. O método `setValue` é usado para alterar o valor e, em seguida, notificar os observadores.

3. **Observer (Monitor)**: A interface `Observador` define a operação `atualizar`, que é chamada pelos observadores quando o sujeito notifica. A classe `Monitor` implementa `Observador` e imprime o novo valor sempre que é notificado.

4. **ConcreteObserver (Monitor)**: A classe `Monitor` é um observador concreto que mantém a lógica de atualização. Quando notificado, ele imprime o novo valor.
