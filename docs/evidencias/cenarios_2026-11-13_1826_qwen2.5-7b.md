## D6

**Pergunta anterior do tutor (contexto fixo):** Quer ver um exemplo em Java?

**Pergunta:** sim

```java
interface Observador {
    void atualizar(String mensagem);
}

interface Sujeito {
    void anexar(Observador o);
    void desanexar(Observador o);
    void notificar();
}

class Notificador implements Sujeito { // ConcreteSubject
    private final List<Observador> observadores = new ArrayList<>();
    private String mensagem;
    public void anexar(Observador o) { observadores.add(o); }
    public void desanexar(Observador o) { observadores.remove(o); }
    public void notificar() {
        for (Observador o : List.copyOf(observadores)) o.atualizar(mensagem);
    }
    public void setMensagem(String m) { this.mensagem = m; notificar(); }
}

class Email implements Observador { // ConcreteObserver
    public void atualizar(String m) {
        System.out.println("Email enviado: " + m);
    }
}

class SMS implements Observador { // ConcreteObserver
    public void atualizar(String m) {
        System.out.println("SMS enviado: " + m);
    }
}
```

### Explicação
1. **Interfaces e Papéis**: `Observador` é a interface que define a operação de atualização (`atualizar`). `Sujeito` é a interface que define as operações de adicionar, remover e notificar observadores.
2. **ConcreteSubject**: `Notificador` implementa `Sujeito` e mantém uma lista de observadores. Ele notifica todos os observadores sempre que a mensagem (`mensagem`) é alterada.
3. **ConcreteObservers**: `Email` e `SMS` implementam `Observador` e fornecem implementações para `atualizar`, que imprimem mensagens indicando que um e-mail ou SMS foi enviado.

## C2

**Pergunta:** Dê um exemplo de aplicação do padrão Observer em Java.

```java
interface Observador {
    void atualizar(String notificacao);
}

interface Sujeito {
    void anexar(Observador o);
    void desanexar(Observador o);
    void notificar();
}

class Notificacao implements Sujeito {
    private final List<Observador> observadores = new ArrayList<>();
    private String mensagem;

    public void anexar(Observador o) { observadores.add(o); }
    public void desanexar(Observador o) { observadores.remove(o); }
    public void notificar() {
        for (Observador o : List.copyOf(observadores)) o.atualizar(mensagem);
    }

    public void setMensagem(String m) {
        this.mensagem = m;
        notificar();
    }
}

class Email implements Observador {
    public void atualizar(String notificacao) {
        System.out.println("Email enviado: " + notificacao);
    }
}

class SMS implements Observador {
    public void atualizar(String notificacao) {
        System.out.println("SMS enviado: " + notificacao);
    }
}
```

### Explicação
1. **Interface `Observador`**: Define a operação `atualizar`, que será chamada quando o `Sujeito` notificar os observadores.
2. **Interface `Sujeito`**: Define os métodos `anexar`, `desanexar` e `notificar`, que são responsáveis por gerenciar os observadores e notificá-los.
3. **Classe `Notificacao`**: Implementa a interface `Sujeito` e armazena uma lista de observadores. O método `notificar` percorre a lista de observadores e chama `atualizar` em cada um.
4. **Classe `Email`**: Implementa a interface `Observador` e define a ação a ser realizada quando notificado.
5. **Classe `SMS`**: Também implementa a interface `Observador` e define a ação a ser realizada quando notificado.

### Questão ao Estudante
Qual método do `Sujeito` é chamado quando uma nova notificação é definida, e por que ele é importante para o padrão Observer?
