## C2

**Pergunta:** Dê um exemplo de aplicação do padrão Observer em Java.

```java
interface Observador {
    void atualizar(int novoStatus);
}

interface Sujeito {
    void anexar(Observador o);
    void desanexar(Observador o);
    void notificar();
}

class Usuario implements Observador {                    // ConcreteObserver
    private int status;
    public void atualizar(int novoStatus) {
        this.status = novoStatus;
        System.out.println("Status atualizado para: " + status);
    }
    public int getStatus() { return status; }
}

class Notificador implements Sujeito {                   // ConcreteSubject
    private final List<Observador> observadores = new ArrayList<>();
    private int status;
    public void anexar(Observador o) { observadores.add(o); }
    public void desanexar(Observador o) { observadores.remove(o); }
    public void notificar() {
        for (Observador o : List.copyOf(observadores)) o.atualizar(status);
    }
    public void setStatus(int novoStatus) {
        this.status = novoStatus;
        notificar();
    }
}

public class ObserverExemplo {
    public static void main(String[] args) {
        Notificador notificador = new Notificador();
        Usuario usuario1 = new Usuario();
        Usuario usuario2 = new Usuario();
        notificador.anexar(usuario1);
        notificador.anexar(usuario2);
        notificador.setStatus(1);  // Notifica ambos os observadores
        System.out.println("Status do usuário 1: " + usuario1.getStatus());
        System.out.println("Status do usuário 2: " + usuario2.getStatus());
    }
}
```

### Explicação

1. **Interface `Observador`**: Define a interface de atualização que os observadores devem implementar. Neste caso, o método `atualizar` é chamado quando o estado do sujeito muda.

2. **Interface `Sujeito`**: Define as operações que o sujeito deve oferecer. As operações incluem anexar e desanexar observadores, bem como notificar todos os observadores quando o estado muda.

3. **Classe `Usuario`**: Implementa a interface `Observador` e mantém o estado atual. Quando o método `atualizar` é chamado, o estado do usuário é atualizado e exibido.

4. **Classe `Notificador`**: Implementa a interface `Sujeito` e mantém uma lista de observadores. Quando o método `setStatus` é chamado, o estado do notificador é atualizado e todos os observadores são notificados.

5. **Classe `ObserverExemplo`**: Exibe um exemplo de uso, onde um notificador notifica dois usuários sobre um novo status.
