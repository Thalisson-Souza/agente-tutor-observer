# Tema "Minimal"

`minimal.json` é o tema Gradio "Minimal", de Taithrah, copiado sem alterações de
https://huggingface.co/spaces/Taithrah/Minimal (arquivo `themes/theme_schema@0.0.2.json`,
baixado em 11/11/2026). Licença: Apache License 2.0.

Fica no repositório para a interface funcionar sem internet. As fontes do tema (Source Sans
Pro e Ubuntu Mono, do Google Fonts) são trocadas em `interface/web.py` pela Source Sans 3,
que vem embutida no Gradio (mesma família, nome atual), e pela Ubuntu Mono instalada no
sistema, com fontes de reserva.
